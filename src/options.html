划词译 · 设置

权威词典开箱即用；机器翻译与模型通道按需填自己的密钥，也有一条零配置通道。

1. 翻译通道

七条通道。「主通道」决定单词/短语用哪个；句子可以单独指定通道（第 7 节）。本地模型与免费机器翻译完全不需要注册。
Chrome 内置 AI 需 Chrome 138+ 且硬件达标（>4GB 显存，或 16GB 内存 + 4 核，22GB 可用磁盘）。不满足时会自动降级。
勾选哪些通道就并排显示哪些，顺序按上表从上到下固定；至少勾两个才生效，只勾一个会退回单条模式。
并列时不走免费机器翻译兜底——哪一列缺密钥就直接报错，否则两列会显示同一个结果、看不出差别。改了勾选后重新划词即可生效。

2. 自定义模型（OpenAI 兼容）

任何 OpenAI 兼容的 /chat/completions 接口都可以，包括本地 Ollama。不需要开放平台账号。
会自动补上 /chat/completions。本地 Ollama 填 http://localhost:11434/v1。
保存在本机 chrome.storage.local，不会上传到任何地方。

3. DeepL（长句 / 整段翻译推荐）

长句和整段译文质量最好的机器翻译，语气与术语保持明显优于通用 MT。Free 档每月 50 万字符，注册只需邮箱。
在 deepl.com/pro-api 选 Free 档申请。以 :fx 结尾的是 Free Key（自动走 api-free.deepl.com），否则走 Pro。Key 只保存在本机。

4. Microsoft Translator（Azure AI 服务）

必应翻译的官方继任者，110+ 语言，支持自动检测语种。免费档 F0 每月 200 万字符。
Azure 门户 → 创建「翻译器（Translator）」资源 → 密钥与终结点里复制。Key 只保存在本机。
资源「位置/区域」的短名，例如 eastasia、westeurope、eastus。多服务/全域资源填 global。

5. Google Cloud Translation

v2 Basic 接口，用 API Key 直连（v3 需要服务账号 JWT，不适合纯客户端扩展）。前 50 万字符/月免费。
Google Cloud 控制台 → 启用 Cloud Translation API → 凭据 → 创建 API 密钥。建议在密钥上限制来源为「无限制」以外的 HTTP 引用（扩展请求不带 Referer，这里只能靠限制 API 类型）。

6. LibreTranslate

开源翻译后端，可自建（docker run libretranslate/libretranslate），自建实例通常免密钥，数据完全自己掌握。
自建填 http://localhost:5000；官方公共服务 https://libretranslate.com 现在需要注册拿 Key。

7. 句子翻译

句子和单词的诉求不同：单词要释义，句子要通顺。这里单独配句子的通道与显示方式。
例如单词用本地模型快速看释义，长句交给 DeepL。
面板标题栏上也有一个「译文 / 对照 / 原文」按钮，划词后可当场切换。
「按句拆分」会把整段切成一句句分别请求，对照模式更整齐，也更容易命中缓存；关掉则整段一次请求（更快，但对照只能整块显示）。
「也查词典」默认关闭 —— 词典查不到整句，开着只会多一次网络往返。

8. 翻译行为

控制译入语言与划词交互方式。
原文已是中文时，自动改译为英语。

9. 词典来源

均可单独关闭。Cambridge / Merriam-Webster / Collins 官网以跳转方式提供原文；词典区块默认展开。

11. 使用要点

  1. 在任意网页选中文字 → 点击气泡「译」按钮 → 面板同时给出译文与词典释义。
  2. 气泡贴在选区末尾，鼠标不用走远；面板内按 Esc 关闭；点击页面空白处也会关闭。
  3. 右键菜单「用划词译查询选中的内容」可作为备用入口。
  4. 查询结果本地缓存 7 天，可在弹窗中一键清除。
安全说明：扩展是纯客户端形态，各通道的 API Key 都保存在本机 chrome.storage.local， 不会上传到任何服务器。若要在团队内分发，建议自建一个后端中转服务持有密钥。
